# resolvemyhoa.com

Static marketing site for Resolve My HOA. The homepage is hand-written HTML. Guide pages are generated by `scripts/build_guides.py`; commit the script and its HTML output.

## What the public site may say

Available at [app.resolvemyhoa.com](https://app.resolvemyhoa.com):

- Free notice analyzer
- Accounts
- Document upload and storage
- Saved cases

Not available:

- Letter or email drafts
- Certified or physical mailing (Lob approval is still pending; do not promise a date)
- Case Pass purchases
- Paid petition or hearing services

Coming soon, with no date and no price: drafting and certified mailing.

## Release

GitHub Pages publishes the `main` branch from the repository root to https://resolvemyhoa.com (and www). There is no separate deploy workflow. Merging to `main` publishes the site. Do not merge until the app has passed production acceptance.

## Announcements

The homepage includes an optional feature-update opt-in. It posts to FormSubmit only after a person checks the consent box and submits. Do not submit that form in testing, and do not email existing signups from this repo.

`python3 scripts/check_claims.py` checks the published HTML for retired offers.

Not a law firm and not legal advice.
