# resolvemyhoa.com

One-page waitlist site for Resolve My HOA. Static HTML, no build step.

- Hosting: GitHub Pages from `main` (root).
- Signups: the form posts to FormSubmit, which emails each signup to the waitlist inbox and keeps an archive retrievable with its API key.
- Custom domain: resolvemyhoa.com (CNAME file), same setup as tiltkiller.com.

Not a law firm and not legal advice.
